## Learning Objectives
- Apply the **First-In, First-Out (FIFO)** principle to manage sequential operations.
- Choose and implement the appropriate data structure (`Queue`) required for the project.
- Integrate both algorithms and data structures into a functional console-based Java application.
- Practice user input validation and error handling to ensure program stability.

---

## Project Description
A console-based Java application that simulates how a printer handles consecutive file printing using data structures and queue algorithms.

---

## Probable Features
1. **Add Print Job**: Enqueue a new file/document into the printing queue with details like a file name, file type, and page count.
2. **Process / Print Next Job**: Dequeue the next file in line to simulate printing it sequentially (**FIFO**).
3. **View Current Queue (Peek/Display)**: Display all files currently waiting in line without removing them.
4. **Cancel / Remove Specific Job**: Terminate or remove an ongoing or queued print job safely.
5. **Check Queue Status**: View the total number of files waiting and check if the queue is empty (`Quick Queue View`).
